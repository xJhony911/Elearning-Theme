# Textos para las tiendas

## Nombre

ESPOCH Themes

## Resumen

Personaliza el aula ESPOCH: ocho estilos, fuentes, tamaño del texto, colores y opciones de lectura.

## Descripción

Dale tu estilo al aula virtual de ESPOCH. Elige entre cinco ambientes oscuros y tres claros, ajusta la fuente y el tamaño del texto y crea tu propia combinación de colores.

Incluye vista previa, ajuste de interlineado, redondeado de tarjetas, subrayado de enlaces, reducción de animaciones y aviso de contraste. Los cambios se guardan automáticamente y se aplican en las pestañas del aula. Puedes volver al diseño original con un interruptor.

Funciona únicamente en https://elearning.espoch.edu.ec/. No recoge datos personales, no tiene publicidad y no necesita servicios externos. Las preferencias se guardan localmente en el navegador.

Proyecto independiente de la comunidad. No está afiliado ni respaldado oficialmente por ESPOCH. No modifica tus entregas, cuestionarios ni calificaciones.

## Propósito único / justificación de permisos

Personalización visual y comodidad de lectura del aula virtual ESPOCH. Se solicita `storage` para guardar preferencias locales. El script de contenido se limita al dominio exacto del aula para aplicar las reglas visuales. No se solicitan cookies, historial, acceso a todas las páginas, descargas, interceptación de red o credenciales.

## Notas para revisión

La portada pública del dominio permite comprobar los estilos sin iniciar sesión. Las páginas académicas requieren una cuenta universitaria; el desarrollador no incluye credenciales reales. Los ajustes pueden probarse desde el menú, que incluye vista previa. El código distribuido es el JavaScript y CSS fuente, sin minificación ni código remoto. Las herramientas y simulaciones de pruebas no están en el paquete de la extensión.

Completa los datos de soporte y enlaces con los de tu cuenta. Las capturas de pruebas deben etiquetarse como demostración; prepara capturas reales con tu sesión sin mostrar datos de otros estudiantes antes de publicar la ficha.
